먼저 한 번 만들어봅니다 15분 미니 실습

여러분이 오늘 응답한 설문 데이터로 만든 예시입니다. 아래 기획안과 프롬프트를 그대로 복사해 AI 도구에 넣어보세요. 기획안이 어떻게 웹앱이 되는지 먼저 겪어보는 것이 목적입니다.

이 예시는 연습용입니다. 지구과학 내용이 아니라 데이터를 다루는 방법을 익히기 위한 것입니다. 여러분의 실제 주제는 4단계에서 고릅니다.
MBTI 성향별 복숭아 선호 더미 데이터
실제 설문 연동 시 이 자리에 실시간 응답이 들어옵니다
E와 I 사이의 차이는 몇 %p 수준입니다. 이 정도 차이는 표본이 100명 남짓일 때 우연히도 충분히 나타납니다. "차이가 없다"는 것도 정직한 결과입니다.

작은 집단은 가립니다

반별 × MBTI 유형처럼 잘게 나누면, 해당하는 사람이 3~4명뿐인 칸이 생깁니다. 학급 규모에서는 이것만으로 누구인지 짐작될 수 있습니다.

구분응답표시
E · 물복30명공개
I · 딱복23명공개
1반 · ENFP3명데이터 부족 — 가림

이 웹앱이 지킨 것

· 이름, 학번, 이메일을 한 건도 받지 않았습니다.
· 원본 응답 시트가 아니라, 개인정보를 지운 공개용 시트만 불러옵니다.
· 코드 어디에도 인증키가 없습니다. 누구나 열 수 있는 공개 주소만 씁니다.
· 응답자가 5명 미만인 조합은 자동으로 가립니다.

이 예시의 기획안 요약

관찰복숭아 취향이 성격과 관련 있다는 속설이 있다
연결우리는 자주 데이터 없이 느낌만으로 관계를 믿는다
임팩트직접 세어보면 속설이 맞는지 우연인지 구분할 수 있다
요청그럴듯한 이야기를 만나면, 먼저 숫자를 확인해보자

복사될 프롬프트 미리보기

대기·해양 단원 수행평가용 데이터 시각화 웹앱을 만들어줘.

[주제] 학급 설문 데이터로 "복숭아 취향과 성격은 관련 있을까" 검증하기
[전달 메시지] 그럴듯한 이야기를 만나면 먼저 데이터를 확인하자
[읽는 사람] 통계를 배우지 않은 일반인
[데이터] 아래 공개 CSV 주소에서 불러올 것 (인증 불필요)
[분석] 전체 비율 집계 → E/I 교차 비교 → 표본 크기의 한계 설명
[시각화] 막대그래프 사용. 파이차트는 쓰지 말 것.
[화면] 홈 / 전체 결과 / 교차 분석 / 함정 주의 / 마무리 메시지

[반드시 지킬 것]
- 방문자의 개인정보를 수집하지 않는다. 로그인, 이름·이메일 입력,
  위치추적 기능을 넣지 않는다.
- 코드 안에 API 키, 토큰, 비밀번호를 절대 하드코딩하지 않는다.
- 인증키가 필요한 외부 API를 쓰지 말고, 공개된 CSV나 내장된
  정적 데이터만 사용한다.
- 응답자가 5명 미만인 조합은 "데이터 부족"으로 표시하고 수치를 가린다.
- 그래프의 세로축은 0에서 시작한다.

주황색 부분은 여러분이 어떤 주제를 고르든 자동으로 붙는 공통 규칙입니다.
