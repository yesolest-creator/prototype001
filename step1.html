STEP 01 / 06 · 목표와 평가 ← 메인 페이지

이 프로젝트에서 무엇을 하나요

여러분은 데이터 커뮤니케이터입니다. 대기·해양 관측 데이터를 분석해, 그 주제를 전혀 모르는 사람에게 전달하는 웹앱을 기획하고 만듭니다.

핵심 질문

숫자로 가득한 관측 데이터를, 과학을 모르는 사람도 이해하고 신뢰하게 만들려면 무엇이 필요한가?

내가 고른 데이터는 정말 내 주장을 뒷받침하는가?

기억할 것

좋은 과학 커뮤니케이션은 화려한 기술이 아니라 정확성 + 명료성 + 읽는 사람에 대한 배려에서 나옵니다.

그래서 이 수행평가는 완성된 웹앱의 디자인보다 기획 과정을 더 크게 봅니다.

평가 기준 세부 배점 확정 예정

영역무엇을 보나
과학적 타당성데이터 출처의 신뢰도, 분석 방법의 적절성, 교과 내용과의 연결
기획의 구체성읽는 사람 설정, 전달 메시지의 명확성, 화면 구성의 논리
데이터 리터러시원자료를 가공한 흔적, 시각화 선택의 근거, 상관과 인과의 구분
의사소통 효과성비전문가 기준 이해 가능성, 과장이나 왜곡 없는 정직한 표현
완성도 가중치 낮음최종 웹앱의 기능과 디자인

4차시 일정

1차시
방향 잡기
목표·평가 기준 확인 → 상관과 인과 학습 → 예시 미니 실습 → 모둠·주제 정하기
2차시
기획안 쓰기
데이터 소스 탐색 → Teams에서 모둠 기획안 작성 → 웹앱에 업로드해 PDF·프롬프트로 변환
3차시
만들기
교사 피드백 반영 → 프롬프트로 웹앱 제작 착수
4차시
공유하기
제작 마무리 → 배포 → 갤러리워크로 서로의 웹앱 살펴보고 의견 남기기

제출물 세 가지

① 기획안 PDF2차시 제출 · 기획 구체성·타당성 평가 근거
② 결과 보고서 PDF4차시 제출 · 웹앱 스크린샷, 분석 결과, 기획과 달라진 점
③ 웹앱 파일 + 배포 링크4차시 제출 · 실제 작동하는 결과물
